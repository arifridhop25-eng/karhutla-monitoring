DATA INGESTION

Tambah Data Spasial

Unggah hasil pengolahan dari QGIS, ArcGIS Pro, atau perangkat lunak GIS lainnya.

▱

Vektor: GeoJSON / JSON

Untuk titik hotspot, batas administrasi, area terbakar, dan kelas kerawanan.

▦

Shapefile (ZIP)

ZIP harus berisi komponen .shp, .shx, .dbf dan disarankan .prj.

▥

Raster: GeoTIFF

Untuk hasil klasifikasi, indeks, atau raster kerawanan. Raster besar mungkin membutuhkan waktu dan memori.

▤

Tabel: CSV / Excel

CSV/Excel dengan kolom koordinat latitude dan longitude dapat ditampilkan sebagai titik.

▧

Gambar peta: PNG / JPG

Tambahkan gambar peta sebagai overlay. Masukkan batas koordinat geografis gambar.

⇄

GeoPackage (GPKG)

Versi browser ini belum membaca GPKG secara langsung. Ekspor layer dari QGIS menjadi GeoJSON, lalu unggah di sini.

  1. Klik kanan layer GPKG di QGIS.
  2. Pilih Export → Save Features As.
  3. Pilih format GeoJSON dan CRS EPSG:4326.
  4. Unggah hasil GeoJSON.
Catatan koordinat: Untuk GeoJSON dan data titik, gunakan sistem koordinat geografis WGS 84 (EPSG:4326). Untuk GeoTIFF, gunakan raster yang memiliki informasi CRS/georeferensi yang benar. File yang dipilih diproses di browser dan tidak diunggah ke server.
INFORMASI PLATFORM

Tentang Sistem

Platform visualisasi informasi spasial kebakaran hutan dan lahan.

Kalimantan Fire Monitoring System

WebGIS ini dirancang sebagai antarmuka untuk menyajikan hasil pengolahan data kebakaran hutan dan lahan di Pulau Kalimantan. Pengguna dapat memuat data vektor, raster, tabel koordinat, serta gambar peta untuk ditampilkan pada peta interaktif.

Catatan penggunaan ilmiah

Angka statistik pada dashboard dihitung dari data yang dimuat dan atribut yang dikenali. Luas terbakar hanya dijumlahkan jika tersedia atribut luas yang sesuai, misalnya area_ha, luas_ha, atau area_km2. Pastikan definisi atribut, satuan, tahun, sumber data, dan sistem koordinat diverifikasi sebelum digunakan dalam laporan atau publikasi.

Website versi ini merupakan prototipe sisi-klien. Data yang dimuat tidak tersimpan permanen setelah halaman ditutup atau dimuat ulang.
